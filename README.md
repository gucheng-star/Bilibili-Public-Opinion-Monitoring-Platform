本地优先的 B站视频评论舆情分析工具。输入 BV 号或视频链接后，你可以在自己的电脑上抓取评论、查看情感与人群分布、分析关键词，并按需要使用大模型辅助研判。

## 版本状态

当前版本为 **0.1.0**，仍处于预发布阶段，尚未进入稳定正式版。功能、数据结构和使用方式可能继续调整，请在更新前备份应用同级的 `data/` 目录。

## 主要功能

- **本地抓取与保存**：评论抓取请求从你的电脑发出，分析记录保存在本机。
- **扫码登录**：登录二维码在本机生成，不依赖第三方二维码图片服务。
- **单视频分析**：输入 BV 号或视频链接，抓取评论并生成可视化结果。
- **多视频舆情事件**：将 2 至 10 个已有视频分析组合为一个事件，观察整体舆情及各来源占比。
- **本地情感分析**：默认先运行本地 NLP，不会自动产生大模型费用。
- **可选大模型研判**：由你主动开启更细致的情感分析或 AI 舆情简报。
- **多维可视化**：查看情感、性别、地域、时间热度、关键词和词云；地域档位可以点击隐藏或恢复。
- **重复内容筛选**：识别文字完全相同的评论，可选择全部保留、每组保留一条或排除整组。
- **统一筛选**：筛选条件会同步作用于图表、评论列表、词云和之后手动生成的 AI 简报。
- **历史记录**：本机保存已完成的单视频分析和舆情事件，便于继续查看。

“重复内容”只表示评论文字完全相同，不代表水军、机器人、异常账号或恶意行为。

## 下载与使用

1. 打开 [GitHub Releases](https://github.com/gucheng-star/Bilibili-Public-Opinion-Monitoring-Platform/releases)。
2. 下载最新的 `BiliOpinionMonitor-<版本>-windows-x64.exe`。
3. 将 EXE 放在有写权限的目录，例如 `F:\Apps\BiliOpinionMonitor`。
4. 双击运行，首次启动时应用会在 EXE 同级创建 `data/` 目录。
5. 扫码登录后输入 B站视频链接或 BV 号，即可开始分析。

程序为 Windows x64 单 EXE 便携版，无需另外安装 Python、Node.js 或 Rust。

> **重要：** 删除 `data/` 会永久删除本机数据库、登录信息、模型设置和分析记录。更新或移动程序前，请先备份整个 `data/` 目录。

## 数据与隐私

- B站请求使用当前电脑的网络出口 IP 和本机登录 Cookie，不经过项目自建服务器中转。
- SQLite 数据库、登录信息、模型配置、日志和分析记录保存在 EXE 同级 `data/` 目录。
- Windows 桌面版使用当前 Windows 用户的 DPAPI 加密 Cookie 和模型 API Key。
- 默认本地 NLP 不调用付费模型。
- 只有在你主动使用大模型功能时，必要的评论文本才会直接发送给你配置的模型服务商。
- 筛选、图表切换和词云重算不会自动调用大模型。

将应用复制到另一台电脑后，历史数据库仍可保留，但由于 Windows 加密绑定当前用户，Cookie 和模型 API Key 需要重新录入。

## 系统要求

- Windows 10 1803（内部版本 17134）或更高版本，64 位。
- Microsoft Edge WebView2 Runtime，多数 Windows 10/11 设备已自带。
- 可以正常访问 B站的网络环境。
- 程序所在目录具有写入权限。

预发布版本可能未进行商业代码签名，因此 Windows SmartScreen 可能显示安全提示。请只从本仓库 Releases 下载程序，并核对发布页提供的文件信息。

## 使用提示

### 为什么抓取到的评论数可能少于页面显示？

B站接口存在分页、删除评论、账号权限和访问频率限制，最终数量以本次实际成功抓取并保存的评论为准。

### 为什么没有年龄分析？

B站公开评论数据不提供可靠年龄字段，本项目不会根据昵称、头像或内容推测用户年龄。

### 为什么地域只能看到省级地区？

评论可获得的地域信息通常只到省级粒度，系统不会推测更精确的位置。

### 为什么移动到另一台电脑后需要重新登录？

Cookie 和模型密钥使用 Windows 用户级加密。复制 `data/` 可以保留历史记录，但换电脑或换 Windows 用户后需要重新扫码登录并输入模型密钥。

### 应用提示无法保存数据怎么办？

请把 EXE 移到当前用户可以写入的目录，并确认 EXE 同级的 `data/` 目录没有被设置为只读，也没有被其他程序阻止访问。

## 已知限制

- 评论数量受 B站分页和风控策略影响。
- 地域信息仅支持省级粒度。
- 本地 NLP 适合快速查看整体趋势，不等同于人工标注或专业研究结论。
- 大模型结果可能出现误判，重要结论应结合原始评论人工复核。
- 当前仅提供 Windows x64 便携版。
